# @smashcut/core

The timeline model for [smashcut](https://github.com/volodymyrrudyi/smashcut): builders (`defineVideo`, `series`, `text`, `video`, …), animation, typing, subtitles and generated audio.

```ts
import { defineVideo, text } from "@smashcut/core";
```

See https://github.com/volodymyrrudyi/smashcut for documentation and examples.
